# chatbox
Basic Chatbot

Description

This is a simple rule-based chatbot built using Python. The chatbot responds to predefined user inputs such as greetings, questions, and farewells.

Features

- Greets the user
- Responds to common questions
- Handles unknown inputs
- Exits when the user types bye

Technologies Used

- Python 3

How to Run

1. Open the project in Visual Studio Code.
2. Run the program:
   python chatbot.py
3. Start chatting with the bot.

Concepts Used

- "input()"
- "print()"
- "if-elif-else"
- "while" loop
- String methods ("lower()")
